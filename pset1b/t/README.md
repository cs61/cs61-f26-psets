# Pset 1b tests directory

You can populate this directory with whatever default tests you’d
like. Any file named `*.cc` is treated as a default test, and should
successfully link against any M61 allocator. After being built,
run a test on the command line with a command like `./t/testname`.
Exiting with status 0 means the test passed; exiting with any other
status means it failed.
